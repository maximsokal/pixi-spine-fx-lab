## Proposed decisions for approval

- Independent editor, 40-frame default one-shot; exact transparent FX at frame 0 and 39 and beyond. Two modes: continuous Dash and discrete Teleport. Dash starts with an editable open cubic path, 170 logical px; issue's progress curve 0/.2/.5/1 -> 0/.1/.9/1 represents normalized arc distance, not Bezier parameter. Require monotonic progress; support linear/Bezier/stepped, with each stepped jump a true discontinuity (no phantom interpolation, distance credit or ribbon bridge). Teleport holds source until editable teleportFrame (default 16), snaps exactly to destination, no distance echoes along untraveled path. Time echoes may be born before/after jump; flash at endpoints. No initial loop promise.
- Afterimage Count 5 (0–24) means maximum scheduled births per emitter per one-shot, not simultaneous visible copies. Time gap 3 frames, first birth after one interval (oracle 3,6,9,12,15). Distance gap 14 logical authoring px before uniform anchor scale (oracle 14,28,42,56,70 on straight continuous path); world gap scales with instance scale. Separate selected rate/interval frequency source, independent rate/interval/spacing curves, seeded jitter, burst count/delay and minimum gap. Use shared arc oracle <=0.25 px. Invert progress segment-by-segment only on continuous motion; never interpolate through stepped jumps. Explicit count cap, no silent eviction. Echo lifetime default 18 frames; alpha scalar .6 multiplied by normalized curve 1 -> 7/12 -> 0 yields .6 -> .35 -> 0, not double alpha multiplication. Separate stable birth timestamp, sampled animation time, position, distance, tangent, age and RGBA.
- Historical poses: use bounded independent Spine models sharing parsed SkeletonData/atlas textures, each with own Skeleton/AnimationState and absolute birth-time pose/skin; never advance or replace the live source pose. Keep texture owner alive until all clones destroyed. No frame-by-frame GPU readback. Alternative texture snapshots add PMA, memory and backend parity risk; do not select initially. Procedural no-asset placeholder does not certify real Spine pose fidelity. No full-affine or attachment anchor promise.
