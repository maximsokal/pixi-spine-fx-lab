## Design decisions for explicit approval
- 40-frame pickup pulse, default; frame 39 fully transparent, no FX beyond endpoint; 60-frame idle loop, exact t=0/t=1 equality, carry previous-period particles analytically. Nominal lifetime 18 frames, interval 6 frames; staggered seeded births and independent age envelopes, not synchronized disappearance. Optional grouped birth events, bounded explicit timing, no duplicate seam.
- Sparkle Count (12, 1–80) means simultaneous active-star cap, not another rate control or guarantee of 12 visible at all times. Spawn Interval controls actual timestamps, Twinkle Speed (2Hz) only appearance. Size 8px (1–30), Spread Radius 55px (5–230), Halo Radius 40px (0–160). Ring placement uses shared adaptive arc table on a closed four-cubic ring. Independent base gap 18px, minimum gap 3px editable, enforce wrap-around minimum gap separately (shared placement currently only avoids duplicate seam); no silent closer anchors to satisfy cap. Seeded deterministic candidate order independent of temporal settings. If geometry permits only one anchor, accept one; report actual count/cap.
- Four-point stars with alternating outer/inner vertices, editable white/gold RGBA palette, optional soft halo and finite shine band clipped to its own circular region (not a source-skeleton mask). Default only stars enabled; halo/sweep independently controllable and initially off. No full-canvas ray or hidden glow. Natural/Stylized/Magical editable styles.
- Independent per-emitter/layer enable, visible, XY, rotation, scale, delay, seed, world/local/Spine bone anchor. Missing anchor hides dependent layer with diagnostic; never mutates source model. Native Graphics/mesh with bounded pooled resources. Reuse shared contracts unchanged; do not import unrelated effect's runtime. Keep pinned Pixi 8.22.0 / Spine 4.2.120, no CDN.
