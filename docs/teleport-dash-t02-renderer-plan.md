## Proposed architecture and constraints (approval required)

Choose independent bounded Spine clones sharing parsed data/atlas textures, not capture-to-texture (readback/PMA/memory) or mutating live Skeleton (corrupts source and order). Native Pixi MeshSimple/Graphics composition, no new filter/shader dependencies. No cross-effect runtime imports, no vendor upgrades.

Coordinate contract: T01 echo descriptor is target pivot/rotation/uniform scale. Effective anchor is layer anchor (inherit resolves emitter). Reference F for world is fitted source center (256,256) with identity rotation/scale; for local/bone F is historical projected uniform host-space anchor. With baseline model transform M and target descriptor D, clone transform = D * inverse(F) * M. Prevent double rotation/scale and verify against independent oracle. Source is independent, not moved to dash head. Missing bone hides only dependent layer; no exact shear/reflection/nonuniform or slot/attachment promise. No fake no-asset silhouette, explicit diagnostic and other layers still render.

Historical posing: source, scratch sampler, echo clones own independent Skeleton and AnimationState, autoUpdate=false, no FX event callbacks. Absolute sourceSeconds times validated speed, explicit animation/skin/loop options. Reset tracks, skin/setup, skeleton.time and physics state before replay. Physics requires fixed 60Hz source-clock replay plus fractional remainder. Nonphysics direct seek permitted only with numerical state parity, otherwise replay. Cache stable birth ID plus asset/options generation; invalidate on changes; no unbounded per-frame cache. Historical anchor sampling never mutates live source. Source preview should use same policy for physics in T03. Proposed bounds: <=3600 fixed source frames per replay, <=200000 fixed updates per generation/seek; preflight actual schedule/speed, reject over budget explicitly. <=96 echo clones (sum of enabled scheduled per-emitter births), one scratch and one source; <=24000 cloned bones and <=24000 cloned slots. No allocation growth after warmup. Select explicit requested skin before fit; absent selection: visible default else first visible named skin in declared order, report actual selection. Invalid explicit skin rejected, old preview preserved. Consistent fitted basis across source/scratch/clones. Preserve exact normalized atlas matching, unique basename fallback, strict JSON/SKEL 4.2.x, texture ownership, detached source Map. Destroy clones/scratch/source before wrappers/ImageSources; model.destroy({children:true,texture:false,textureSource:false}), never destroy shared host or textures from clone; idempotent teardown.
